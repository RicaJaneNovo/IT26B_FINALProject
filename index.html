🗄️ Database Structure

PawDiary uses 5 related tables in MySQL

👤 users

  • user_id (PK)
  • username
  • email
  • password
  • full_name
  • bio
  • profile_pic
  • created_at

🐶 pets

  • pet_id (PK)
  • user_id (FK)
  • pet_name
  • species
  • breed
  • age

📋 activities

  • activity_id (PK)
  • pet_id (FK)
  • activity_type
  • description
  • activity_date

🏥 health_records

  • record_id (PK)
  • pet_id (FK)
  • record_type
  • notes
  • record_date

🔗 SQL Join Integration

All 4 types of SQL joins are used in PawDiary

🔵 INNER JOIN

Returns only activities that have a matching pet in both tables. Used in the dashboard to display the activity log.

🟢 LEFT JOIN

Returns all pets even if they have no activities logged yet. Used to show complete pet list with activity counts.

🟠 RIGHT JOIN

Returns all activities even if the pet record no longer exists. Ensures no activity data is lost.

🟣 FULL OUTER JOIN

Shows all pets and health records whether matched or not. Simulated using UNION of LEFT + RIGHT JOIN in MySQL.
